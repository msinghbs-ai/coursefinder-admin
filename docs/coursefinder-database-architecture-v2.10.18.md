## Canada Layer 1 identity

Provider identity remains `CA + ircc_dli + DLI_number`.

Course identity remains `UUIDv5(verified IRCC DLI + namespaced stable institutional/source-local programme key)`.

Titles are mutable and are never identity. Admissions/intake availability remains separate from Course lifecycle unless the source explicitly provides a lifecycle state.

## Northern parser boundary

Northern's dedicated Post-Secondary Programs source returns 53 programme pages through its supported AJAX feed. Strict parsing currently proves 35 valid institutional code records while 36 pages expose alternate code markup. The loose parser was rejected because it could capture unrelated uppercase tokens. No Northern APPLY is permitted until every identity is extracted only from explicit programme-code surfaces.
