# CourseFinder Engagement Time Log

**Purpose:** Durable interaction/time reference for invoicing and engagement review.

## Operating rule

- Record user interaction/session timestamps and the workstream discussed or advanced.
- Do **not** automatically convert elapsed chat/session time into billable hours.
- Billable/engagement hours remain **user-decided** and are recorded only after explicit confirmation.
- Where a session remains open while the user is away, elapsed wall-clock time is not treated as engagement time.
- Keep Milestone 1 as a closed historical billing baseline and record Milestone 2 onward separately.
