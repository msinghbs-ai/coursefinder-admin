## 4. Go 7 — streamlined Data Operations navigation

CF-CHG-20260826-040 is the first active M2.4 change. Its accepted design target is documented in `docs/coursefinder-admin-navigation-information-architecture-v1.4.md`.

Primary operating order:

`Overview → Catalogue → Data Operations → Insights → Quality & Review → Decision Tools → Governance & Platform → Help & Guides`.
