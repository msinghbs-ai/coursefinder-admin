> **API changes (all additive; nothing renamed or removed)**
> - **Website API v2 now has its own address, `website-api-v2`, with its own key** (developer guide issue 3, 16 Oct). Responses carry `api_version: "website-v2"` instead of `contract_version`, and no `contract` field is needed. Error responses add `message` and `detail` (and a new `INVALID_JSON` code). The limit is 300 calls a minute per key, across all actions. The actions, fields and answers are the same as before. **The earlier address keeps working until you've moved.**
