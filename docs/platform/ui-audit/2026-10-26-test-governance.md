## 3 Governance (Part 3): what is now standing

- Pilot `CLAUDE.md` **G4**, admin AGENT-OPERATING-MODEL **rule 11**:
  - every spec starts with `// Guards: <rule or decision>`, and all 281 now do (76 of them newly written from the spec's change id and title, 205 from their existing header);
  - the PR names the guard;
  - the register is regenerated in the same PR;
  - obsolete tests retire with the rule change, logged in the register;
  - no re-assertion of central rules;
  - nothing red or skipped;
  - phone runs only for `@responsive` tests.
- **`tests/uat/cf-247-s120-test-governance-contract.spec.mjs`** fails the build when:
  - a spec has no Guards line;
  - a test is skipped unconditionally, or as `test.skip('…')`, `fixme` or `only`;
  - a local (non-deployed) spec skips for a missing environment;
  - the phone project loses its filter;
  - the legacy baseline is asserted outside `s70`.
- **Monday line**: tests added, retired and net for the week. **Quarterly prune** alongside the docs budget: the remaining duplicated-guard lines and any spec whose guard has been superseded.
